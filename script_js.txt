1. THE UNIVERSAL GET DATA FUNCTION
```javascript
function getData(endpoint, callback) {
    fetch(`${SERVER_URL}/api/${endpoint}`, {
        credentials: "include" // VERY IMPORTANT
    })
    .then(response => {
        if (response.status === 401) {
            window.location.href = 'login.html';
            throw new Error("Not logged in");
        }
        return response.json();
    })
    .then(data => callback(data))
    .catch(error => console.error(`Error loading ${endpoint}:`, error));
}
```
Explanation:
Instead of writing `fetch(...)` twenty different times across the file to ask for Patients, Bills, or Prescriptions, this single utility function handles all GET requests centrally.
`credentials: "include"` ensures the session cookie is strapped to every outbound request. 
The `response.status === 401` block is the universal security fallback mechanism. If the server ever rejects the request because the doctor's login timeout expired, this function immediately hijacks the browser and aggressively forces a redirect to `login.html`, preventing the doctor from staring at a broken, unloaded screen.

2. AUTO-FILLING PATIENT DETAILS ON BLUR
```javascript
function autofillPatientDetails() {
    let nameInput = document.getElementById("patientName").value;
    getData("patients", function(patients) {
        let matchedPatient = patients.find(p => p.name.toLowerCase() === nameInput.toLowerCase());
        
        if (matchedPatient) {
            let treatmentInput = document.getElementById("treatmentName") || document.getElementById("treatmentGiven") || document.getElementById("treatment");
            if (treatmentInput && !treatmentInput.value) {
                // Auto-fill the original problem into the treatment description box
                treatmentInput.value = matchedPatient.problem;
            }
        }
    });
}
```
Explanation:
This function makes the application feel intelligent. It fires the exact millisecond the doctor finishes typing a patient's name into a dropdown text box and clicks away (`onblur`).
It scans the array of all known patients looking for an exact text match (`.toLowerCase()` ensures case-insensitivity so "john" matches "John"). 
If it finds a match, it programmatically hunts down the currently active Treatment text box on the page and automatically injects the patient's original `problem` symptom directly into it, saving the doctor precious typing time.
