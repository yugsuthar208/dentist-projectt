The cover is decorative artwork. The application screenshots in `screenshots/` are actual browser captures using fictional records.

## Cover generation prompt

Use case: ads-marketing. Create one premium editorial GitHub README cover image for a college project called Dental Clinic Management System. Wide 3:1 banner composition, approximately 2400 by 800. Art direction: exceptionally refined Swiss editorial typography combined with a physically rendered porcelain tooth sculpture. Warm ivory paper background, deep midnight navy typography, confident cobalt blue accent, small mint accent. Left 60 percent is spacious typography on ivory, right 40 percent is an elegant large sculptural white molar on a cobalt circular plinth with soft architectural shadows and very subtle concentric connection lines. No people, no user interface mockup, no charts, no invented application screens, no stock medical photograph, no neon, no busy decoration. Sophisticated tactile ceramic material, precise soft studio lighting. Beautifully balanced generous margins. Typography must be sharp and readable when image is displayed at 850px wide. Render these exact words only, using exquisite hierarchy: small upper-left eyebrow "A FULL-STACK COLLEGE PROJECT"; very large main headline on two lines "Care," then "connected."; medium supporting title below "Dental Clinic Management System"; bottom small neat horizontal index "01 PATIENTS     02 TREATMENTS     03 PRESCRIPTIONS     04 BILLING". Main headline is large dark navy contemporary serif with understated expressive character; other text is clean modern sans serif. One small thin cobalt rule near the eyebrow. Clean intentional graphic design, premium publication cover, cohesive composition. This is decorative project cover artwork, not a representation of the actual app. No logos, watermarks or additional text.
