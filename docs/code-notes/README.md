# Earlier code explanations

[← Project README](../../README.md) · [Current project guide](../PROJECT_GUIDE.md)

This folder preserves the explanatory `.txt` files previously stored in the repository root. They contain selected code snippets and learning notes, rather than complete runnable source files.

Some notes describe an earlier version with separate treatment, prescription and billing pages. The current application combines those workflows in `patient-service.html`. Use the source files in the repository root and the current guides as the reference for installation and behavior.

Credential examples have been replaced with placeholders. Configure your own credentials privately through `.env`. Historical commentary in these notes is not a security guarantee or a complete description of the current implementation.
